# Архитектура Vertex

![Схема данных, метрик, ролей и интерфейса](architecture.svg)
Роли и гипотезы описывают наблюдаемые признаки, не виновность.

```mermaid
flowchart TD
 A[Parquet: узлы, рёбра, переводы] --> B[Валидация и сортировка]
 B --> C[Ориентированный взвешенный граф всех узлов]
 C --> D[PageRank, weighted HITS, betweenness, циклы, лаги]
 C --> E[Неориентированная проекция: Louvain seed 42]
 D --> F[Правила ролей: сначала обрезка и стоки]
 E --> G[Приоритет, сообщества и кейсы]
 F --> G
 G --> H[Валидация: 3 CSV + 4 JSON]
 H --> I[build_viz: автономный HTML]
 I --> J[Граф / Кейсы / Устойчивость / Ассистент]
 J --> K[Заметки: браузер + явный экспорт/импорт]
 J -. выбор облачного режима .-> L[Локальный сервер: ключ в окружении]
 L -. ограниченные метаданные .-> M[OpenAI: структурированный фильтр]
 M --> N[Проверка ответа и выбор реальных gid локально]
```

CSV: nodes_roles, clusters, top_nodes. JSON: graph, summary, cases, resilience.
Симуляция удаляет узлы только в модели. Гипотезы CSV и офлайн-ассистент работают без LLM.
Кейсы основаны на сообществах; до 12 наблюдаемых переводов на карточку, полное число показано отдельно.
Состояние кейса не хранится в Git и не синхронизируется само.
