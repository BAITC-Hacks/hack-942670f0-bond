## Формальная проверка пяти областей
1. Роли соответствуют таблице README сверху вниз. Перцентили p98/p95/p90 динамические. Константы 3, 5, .5, .7 и 1.3 остаются фиксированными структурными условиями; утверждать «все пороги перцентильные» нельзя.
2. truncated_by_depth = depth==4 и out_deg==0. Такие узлы terminal с role_score=.35; seed pass_through=-1 и seed не transit.
3. Центральности рассчитываются на DiGraph с денежными весами; для кратчайших путей используется обратная сумма. Louvain — только на неориентированной проекции со сложением встречных потоков.
4. Три CSV, точный порядок колонок и типы проверяются валидатором. Evidence непустое, динамическое, короче 200 символов. JSON и HTML — дополнительные артефакты.
5. seed=42 для Louvain, точный betweenness без выборки. Время расчёта 4.79–5.10 с на текущем Windows/Python 3.12. Обещания 5 минут для произвольной плотной сети нет.
