# Демонстрация «Вершины» — 3 минуты

## 1. Контекст, 20 секунд

«Мы исследуем наблюдаемую сеть из 2248 синтетических участников и 3119 направленных связей.
Инструмент помогает выбрать, какие финансовые связи проверить первыми.
Роли и приоритеты — гипотезы, не утверждения о виновности».

## 2. Overview → focus, 45 секунд

1. Открыть `out/vertex.html` или локальный сервер.
2. Показать общий граф: цвет — роль, размер — приоритет, стрелки — направление.
3. Нажать «Фокус: топ-30 и окружение».
4. Выбрать первую строку очереди проверки.
5. Показать числовое обоснование и входящие/исходящие связи.
   «Этот gid — координирующий кандидат по взвешенным центральностям, а не установленный организатор».

## 3. Две ловушки, 35 секунд

1. Через локальный чат «Слепые зоны» выбрать один из gid.
   Пунктирное кольцо, поддержка правила 0.35, запрос 5-го колена.
   «Все 444 обрезанных узла выделены; отсутствие выхода не доказывает оседание средств».
2. Вернуться к топ-1 seed. Показать предупреждение о неполном входе.
   «Мы не классифицируем seed как транзит на основании некорректного отношения сумм».

## 4. Структура и устойчивость, 45 секунд

1. Сбросить фильтры, выбрать кластер: гипотеза из состава ролей.
2. Включить изоляцию ключевых ролей и подсветку циклов.
   «Красные рёбра входят в полный видимый направленный цикл длиной до 5.
   Это структурный сигнал, не доказательство возврата тех же денег».
3. Сбросить и удалить топ-5 ползунком.
   «Слабосвязных компонент 35 → 128, крупнейшая 1877 → 1723.
   Это симуляция на графе, реальные счета не затрагиваются».

## 5. Прозрачность и результат, 35 секунд

«Взвешенные PageRank, HITS и betweenness; для betweenness расстояние равно обратной сумме.
Louvain работает на явно оговорённой неориентированной проекции, seed=42.
Порог p95 вычисляется без округления; каждый gid сопровождается коротким числовым evidence.
Ровно три CSV, 30 приоритетных узлов, автономный HTML.
Исправленный расчёт на нашем наборе занимает около 3–5 секунд без установки зависимостей».

Опционально при настроенном API: выбрать OpenAI в чате, спросить «Кто главный сборщик от seed?».
Модель интерпретирует фильтр, реальные gid и числа выбирает локальный код.
Без API показать локальный режим и назвать его локальным, не имитировать LLM.
